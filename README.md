# Welcome to Husky Access! 🙌
Husky Access is a platform that aims to accommodate students on the UW campus with accessibility support. 


# Description
The University of Washington is home to over 7,000 students with temporary or permanent accessibility needs. Navigating a campus of this size can be challenging, and many of these students struggle to find accessible routes to class or connect with others who share similar experiences. Husky Access's mission is to provide a solution to this problem. This app's main feature is routing that helps students with disabilities navigate campus. It also includes features such as discussion posts and report-a-problem to help students build a sense of community within the platform and customize it to their needs.

# Running the Project

### Step 1: Clone/Download Files
Clone and download the files from the Husky-Access Github and open in a code editor. 

### Step 2: Expo Go
Expo Go is the mobile app used to run this project's code files. Download it from the app store on a mobile device.  

### Step 3: Dependencies
Once all files are downloaded and opened in a code editor, run `npm install` install in the terminal to add the neccessary packages and dependencies. 

### Step 4: Starting the server
To start a server and view this project, run `npx expo start` and scan the qr code that it generates. The project should then be viewable on a mobile device!


# Help 
If Expo Go pops an error up, try in this order:
- reloading the project through Expo Go (hold three fingers down on the screen, select reload project)
- restarting the server from the code editor with `npx expo start`
- running `npx expo --tunnel` in your terminal
